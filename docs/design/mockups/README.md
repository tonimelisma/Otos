# Design mockups

Visual references for `docs/design/design-system.md` and `docs/design/import-bar.md`,
authored in HTML by the designer. They show intended look, spacing, colour, and
motion — they are not production code, and nothing is ported from them directly.
Otos is SwiftUI/AppKit using the platform's own semantic type styles, label colours,
and control metrics.

**The markdown is authoritative.** Where a mockup and the markdown disagree, the
markdown wins — the import-bar plan's trap table (`docs/plans/0092-*.md`) records
several places an early mockup was wrong and the markdown corrected it.

To view a mockup, open the `.dc.html` file in a browser; `support.js` must sit
beside it.

| File | Shows |
| --- | --- |
| `Otos Import.dc.html` | The import bar's seven states, light and dark. |
| `Otos Design Guidelines.dc.html` | The design system, illustrated. |
| `support.js` | Runtime shared by both mockups. |
