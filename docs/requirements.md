# Otos Requirements

Authoritative registry of **implemented** product and system behavior. A row's
presence means Current. Retired rows are deleted (git history remembers). Process,
workflow, and tooling rules live in `AGENTS.md`, not here.

Every behavior change updates the affected rows in the same PR. Paths in
**Implemented in** and **Tested by** must exist on disk
(`script/requirements-authority-check.sh` enforces this).

Column meanings:

- **ID** — stable identifier (`ARC-*` architecture/system, `APP-*` product surface,
  `ENR-*` enrichment, `MED-*` media/originals).
- **Requirement** — the behavior itself.
- **Acceptance example** — a concrete observable example of the requirement holding.
- **Implemented in** — owning source files.
- **Tested by** — test files, or `manual: <how>` when only manually verifiable.
